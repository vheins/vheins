## What I build

- **Enterprise applications** — ERP, finance, procurement, reporting, approval workflows, and system integrations.
- **AI-agent infrastructure** — local-first memory, codebase intelligence, orchestration, model routing, and autonomous development loops.
- **Production platforms** — reliable Linux environments using Docker, Nginx, PostgreSQL, Redis, HAProxy, and Patroni.
